# Bad Habits

Quit-Habit-App: Gewohnheiten eintragen, von denen man losgekommen ist, und live sehen, seit wann man clean ist.

## Funktionen
- Live-Zähler in Tagen, Stunden, Minuten und Sekunden
- Meilensteine von 1 Tag bis 3 Jahre mit Fortschrittsbalken
- Rückfall-Button, der den Zähler zurücksetzt; Bestzeit und Anzahl der Rückfälle bleiben erhalten
- Sortierung nach Dauer, die kürzeste zuerst

## Nutzung
`index.html` im Browser öffnen oder per GitHub Pages hosten. Außerhalb von Claude werden die Daten im `localStorage` des Browsers gespeichert. Ein Sync zwischen Geräten gibt es nur in der Claude-Artifact-Version.
